How Binary Maps to DNA

Digital data (binary 0s and 1s) is converted to DNA nucleotides in pairs called dibits. Each 2-bit pair maps to one of four nucleotides: Adenine (A), Cytosine (C), Guanine (G), or Thymine (T).

Why 24 Mappings?

There are 4! = 24 possible ways to assign the four nucleotides to the four dibits. The Reinforcement Learning agent learns to pick the best mapping for each data block — choosing one that produces DNA with balanced GC content and minimal homopolymer runs, which reduces sequencing errors.

Dataset

The model is trained on synthetically generated binary data with three controlled distribution profiles, ensuring generalisation across different types of input data.

●

High GC Profile

Binary data biased toward dibits 01 and 10, producing high Guanine-Cytosine content (~70%) under baseline mapping.

●

Low GC Profile

Binary data biased toward dibits 00 and 11, producing low Guanine-Cytosine content (~30%) under baseline mapping.

●

Balanced Profile

Roughly equal dibit frequencies (~25% each), producing balanced Guanine-Cytosine content (~50%) under any mapping.

📚 Curriculum Learning

Epochs 0–33% Balanced only
Epochs 33–66% Mixed profiles
Epochs 66–100% All profiles

📊 Evaluation Setup

  • Sequence Lengths: 64, 128, 256, 512, 1024 nucleotides
  • Trials per Length: 100 frozen evaluation trials
  • Seeds: 7 independent runs
  • Validation: Every 500 epochs on held-out data
  • Error Rates: 2% substitution, 1% insertion, 1% deletion

System Architecture

The system has two complementary layers plus a multi-copy redundancy mechanism.

Layer 1

Reinforcement Learning Encoding Agent (Proximal Policy Optimisation)

A Proximal Policy Optimization agent with a shared Actor-Critic neural network.

State 6-dimension: normalised dibit frequency vector (4) + max frequency + normalised sequence length
Actions 96 composite actions (24 mappings × 4 secondary groups)
Network 2×64 hidden layers, Tanh activation, 10% dropout
⟶ predicted error ⟶
Layer 2

Error Predictor

An MLP that estimates expected sequencing risk from DNA sequence features.

Input GC content, entropy, homopolymers, sequence length, mapping index
Output Predicted error rate (scalar)
⟶ store multiple copies ⟶
Redundancy

Multi-Copy Storage + Majority Voting

1–10 copies stored independently. During retrieval, position-wise majority voting builds a consensus strand.
